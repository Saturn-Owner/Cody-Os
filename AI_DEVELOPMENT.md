# KI-gestützte Entwicklung

CodyOS wurde zu großen Teilen mit KI-Unterstützung entwickelt.

Für die Arbeit an Architektur, Code, Refactoring, Debugging, Tests,
Dokumentation und Sicherheitsprüfungen wurden unter anderem folgende
Werkzeuge genutzt:

- ChatGPT
- Codex / GPT Code
- Claude Code

Die KI-Werkzeuge wurden als Entwicklungs- und Review-Unterstützung eingesetzt.
Sie ersetzen keine menschliche Verantwortung: Änderungen wurden manuell geprüft,
in den Projektkontext eingeordnet und mit den verfügbaren Tests verifiziert,
bevor sie in dieses öffentliche Repository aufgenommen wurden.

CodyOS enthält keine persönlichen Agentendaten, keine privaten Provider-Keys
und keine produktiven Zugangsdaten aus den Entwicklungsumgebungen.
